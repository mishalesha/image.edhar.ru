#### Описание
Вся затея в схемах: куст, ходы, сетка позиций, территории и границы, что не закрыто.

#### Ключевые слова
онтологические дебаты, история, схемы, сборка

# Сборка в схемах

Меньше текста, больше картинок. Схемы — в блоках кода, чтобы держали моноширинный шрифт; в Obsidian и на сайте они читаются как есть.

## Из чего собрано

```
Онтологические дебаты
├── 00 индекс              навигация
├── 01 как это было        хронология и ходы
├── 02 материалы           что советовали друг другу
├── 03 сборка в схемах     эта страница
├── Расшифровки/           13 записей трёх встреч
├── Позиции/               4 карточки
└── Анализ/                карта позиций и сверка со статьёй
```

## Две оси, четыре клетки

```
              ┌──────────────────────┬──────────────────────┐
              │        ЗАКОН         │        ВЫБОР         │
              ├──────────────────────┼──────────────────────┤
   НЕМНОГИЕ   │  ЗАКОНЫ ЭЛИТ         │  ВЫБОР ЭЛИТ          │
   элиты      │  место сильнее       │  решение сильнее     │
              │  человека            │  места               │
              ├──────────────────────┼──────────────────────┤
   МНОГИЕ     │  ЗАКОНЫ МАСС         │  РЕШАЕТ КАЖДЫЙ       │
   каждый     │  система сильнее     │  рассказ сильнее     │
              │  человека            │  системы             │
              └──────────────────────┴──────────────────────┘
```

## Развилка внутри верха

```
        ┌───────────────┐        ┌───────────────┐
        │ ЗАКОНЫ ЭЛИТ   │        │ ВЫБОР ЭЛИТ    │
        │ элита = место │        │ элита = автор │
        └───────┬───────┘        └───────┬───────┘
                │                        │
        «так было неизбежно»     «могло быть иначе»
```

## Как одна позиция звалась по-разному

```
 «Законы масс»   ──▶ «законы больших масс» ──▶ «законы развития больших систем»
 «Законы элит»   ──▶ «законы элит»        ──▶ «закономерности элит»
 «Выбор каждого» ──▶ «решает каждый»      ──▶ «выбор каждого»
 «Решает элита»  ──▶ «выбор элит»         ──▶ «субъектные элиты»
    ветка чата          записи                   статья
```

## Как четыре ответа складываются

```
┌────────────────────────────────────────────┐
│  РАССКАЗ          закрепляет               │
├────────────────────────────────────────────┤
│  ВЫБОРЫ КАЖДОГО   ткань                    │
├────────────────────────────────────────────┤
│  ВЫБОР ЭЛИТ       ветка                    │
├────────────────────────────────────────────┤
│  ЗАКОНЫ           коридор                  │
└────────────────────────────────────────────┘
   снизу вверх: рамка → развилка → ткань → имя
```

## Дерево вопроса

```
        ПОЧЕМУ В ИСТОРИИ ПРОИСХОДИТ ТАК?
                       │
      ┌────────────────┴────────────────┐
 «так устроено»                    «так решили»
     закон                              выбор
  масс · элит                     каждый · элита
```

## О чём спорят на самом деле

```
 «это было неизбежно»   ←  закон
 «это могло быть иначе» ←  выбор
        └── не противоречие, а два вопроса ──┘

 спор о факте  →  проверяется данными
 спор о рамке  →  проверяется только следствиями
```

## Что не закрыто

```
 27.06  ✔ текст
 30.06  ▣ аудио и видео есть, текста нет
 24.07  ✔ текст
 19.10  ✔ часть 1  ·  ⏳ часть 2 (расшифровка идёт)
 ноябрь ✗ встречи не было
 чат    ▣ вложения не выгружены
```
